# 前端边界

前端负责请求、SSE事件消费和已验证业务结果的呈现，不自行拼装健康结论、营养结论或工作流决策文本。

前端已实现：匿名参与者、多轮对话、SSE 事件消费与已验证菜单结果渲染（`frontend/src/`），契约见 `frontend/src/types.ts`。

每次打开页面均进入新的空白对话。从固定的 50 位匿名成员中选择本次参与者，首次发送时创建独立会话；对话开始后成员固定，需要更换时点击“新对话”重新选择。

左侧边栏列出此浏览器中创建的对话。点击历史对话可恢复消息、成员选择与会话并继续交流；刷新页面仍默认进入新的空白对话。对话记录保存在当前浏览器的本地存储中，清除站点数据后无法从侧边栏恢复。

## 验证入口

当前真实 API 为 8003。执行 `npm run test:e2e` 先构建，再运行全部 10 个真实场景；唯一配置为 `playwright.config.ts`，临时前端使用 5176 预览构建产物，避免开发热刷新干扰。通过 `PLAYWRIGHT_REPORT_NAME` 指定新报告名，报告保存至 `../verification/artifacts/`。未指定时生成带时间戳的名称。

单元测试：`npm test -- --run`；构建：`npm run build`。`verification/playwright.audit.config.ts` 仅供模拟接口的恢复交互测试，独立于真实验收。
