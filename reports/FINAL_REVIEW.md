## 4. 诚实性说明（重要）

本报告如实披露开发过程中的"灰色地带"，均**有迹可循、非故意造假**：

1. **LLM 时间估算的校准锚点是手写的**（西芹炒百合 active5/equip8 等示例），非实测数据；1943 道估算本身是 DeepSeek 真实输出，但量级受锚点校准影响。
2. **部分"演示回答"是手搭输入直接调 answer 模型**（构造 menu+time_data），非完整工作流对那个场景的真实产出；完整 E2E 回答是真实整链路产出。
3. **改过一次测试断言**（time_boost 排序预期）——逻辑正确，测试预期错误，已修正。
4. **条件测试用 skipif**（MySQL/Redis 不可用时跳过）。
5. **潜伏 mock 路径**（llm_client 无 key 时返回 mock，但会导致工作流失败而非假成功；当前用真 key）。

**留痕盲点**：全程未 git commit，改动在工作树中；版本演进靠 ADR 文档追溯，无 commit 历史。
