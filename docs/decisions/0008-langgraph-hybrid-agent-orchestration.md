# ADR-0008：受约束的 Agent 工具编排

- 状态：`IMPLEMENTED`（当前入口仅运行 LangGraph v2）
- 日期：2026-09-27
- 适用范围：C3 编排与 D1 入口适配，复用 C4 和 Application 边界
- 详细设计：[09-langgraph-agent-orchestration-redesign.md](../modules/09-langgraph-agent-orchestration-redesign.md)

> 本 ADR 后文保留设计阶段的迁移和回滚表述，作为历史决策背景。实际交付已移除旧确定性编排入口与实现；当前行为和验收证据以[唯一入口方案](../superpowers/plans/2026-09-29-langgraph-v2-entry-convergence.md)及[最终验收](../../reports/2026-09-28-clarification-v2-acceptance.md#9-2026-09-29-langgraph-v2-唯一入口最终验收)为准。

## 背景与选择

当前 fast_path 把行动选择与工具执行耦合在过程分支中。用户希望模型根据目标与执行证据选择下一步，而非仅把固定流程迁入 LangGraph。

固定图改善结构但仍然写死行动；无限制 Agent 难以保证健康、权限与成本。本次选择受约束的行动—工具反馈循环。

## 决策

1. LangGraph 承载 Context、Decide、Gate、Execute、Observe 和交付边界。业务 Agent 选择检索、扩展、审核、规划、历史读取、最终校验、澄清或完成，不动态创建角色或分配权限。
2. 模型只提交类型化行动与证据引用。执行器控制白名单、参数注入、前置条件、证据绑定、状态更新、取消与预算。
3. C1/B2/B4/C2/B5/B6 算法不变。C2 为确定性贪心菜单构建，B5 使用 CP-SAT 时间调度，B6 仍为营养软排序；不新增按人摄入。
4. 不擅自放宽硬要求；可在原条件内搜索，或通过结构化选项协商。下一请求只应用用户接受的变更，永久健康约束不可协商。
5. 诊断限定于实际候选和已有方案；允许原因未知，不把搜索失败说成全库无解，不虚构最短时间或替代方案。
6. 最终健康校验由 Agent 显式发起；finish 门卫验证回执，不能补调。回答通过校验后，沿用结果、审计和 outbox 原子提交，再发布成功事件。
7. C4 保留已提交菜单历史，恢复须按当前事实重验。首期不以 Checkpointer 替换业务版本，不启用跨请求图重放。
8. 保持 API/SSE 协议和 WorkflowRunner 基础执行能力；首期不直推未校验、未提交的模型 token。

## 与已有决策和不变量的关系

- DEC-C011 固定五角色保留给 legacy，新模式使用业务行动选择角色及受控回答步骤。
- DEC-C012/DEC-R004 继续禁止模型动态分配角色、权限与工具；允许在静态白名单内选择业务动作。
- DEC-C013、INV-007 保留：主动调用工具，缺必需回执失败，不由工作流补调。
- 健康、回答绑定、状态所有权、上下文、审计、隐私、有界循环与永久健康约束等全局不变量继续有效。
- ADR-0006 提交后发布、ADR-0007 预计时间语义继续有效。
- 旧 09-agent-workflow.md 的固定角色与拓扑用于 legacy；新模式以本方案行动协议为准。实现前完成角色、工具和 Artifact 映射，不混用旧权限。

## 影响与代价

Agent 真正承担行动选择，失败后搜索和协商不再全部写死；确定性代码继续裁决健康、安全候选来源、菜单身份和提交。

模型往返可能增加，需要预算与场景评估，不承诺框架迁移自然提速。首期保持算法、业务版本和提交协议稳定，工作集中于 C3 契约与适配。

不新增份量、采购量、医学推断或实时流式协议，避免混入其他功能重构。

## 验收与回滚

按详细方案第10节覆盖行动选择、非法调用、证据失效、替换恢复、多轮协商、取消、幂等与事务失败。保留 fast_path/legacy，使用隔离会话对照，禁止同一请求双写。切换前验证新模式澄清数据与旧入口的兼容行为。
